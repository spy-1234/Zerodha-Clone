# 📈 Zerodha Clone – Full Stack MERN Application

A fully responsive stock trading and investment platform inspired by Zerodha, built using the MERN Stack (MongoDB, Express, React, Node.js).
This project replicates core features of a modern brokerage app including user authentication, portfolio tracking, live market data, order placement, and charts.

## 🚀 Features 
🔐 User Authentication (JWT-based login/signup)
📊 Dashboard & Portfolio Tracking
📈 Live Market Data (Mock Market API / WebSockets)
💹 Buy/Sell Order Placement
📃 Order History & Trade Logs
📉 Interactive Stock Charts (Chart.js / TradingView widget)
⚡ Fast & Responsive UI (React + Tailwind/Material UI)
🗄 REST APIs for all trading operations
🧾 Secure Backend with Role-Based Operations
🧪 Modular and Scalable Architecture
🛠 Deployed on Render/Vercel/Netlify + MongoDB Atlas (Optional)

## Frontend:-
1. React.js
2. Redux / Context API
3. Tailwind CSS / Material UI
4. Axios

## Backend:-
1. Node.js
2. Express.js
3. MongoDB + Mongoose
4. JWT Authentication
